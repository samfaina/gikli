## Agent skills

### Issue tracker

Los issues se gestionan en GitHub Issues (samfaina/gikli) con el CLI `gh`. See `docs/agents/issue-tracker.md`.

### Triage labels

Las cinco labels canónicas por defecto: needs-triage, needs-info, ready-for-agent, ready-for-human, wontfix. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: un `GLOSSARY.md` y `docs/adr/` en la raíz. See `docs/agents/domain.md`.
